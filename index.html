Import a Miro board

Brings the board's pictures, text, sticky notes, shapes and frames over, each where it was. Pictures are downloaded at full size into the folder below.

For exact crops: first open the board in Miro, click an empty spot, press Ctrl+A then Ctrl+C. Ozy reads every picture's crop from that copy (Miro's API does not give them). Already imported? Do that, then Import again: nothing is downloaded twice.
A token is saved on this PC; leave the box empty to use it.
In Miro: your profile picture → Settings → Your apps → Create new app (pick the team that has the board). Leave "Expire user authorization token" unticked. Under Permissions tick only boards:read, then Install app and get OAuth token, and copy the token it shows. The token only reads boards; delete the app in Miro to cancel it.
